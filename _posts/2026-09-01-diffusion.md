## [](#prologue)Prologue
Images generated by machine learning models up until the end 2010s were not very impressive compared to today's standards. When diffusion models were introduced and had matured for some years, they really took off. The diffusion model architecture had more stable training, and also enabled some significant tweaks. Today, diffusion models are used to create ultra-realistic images and videos, albeit GANs are much faster at inference, and therefore still viable in that sense. This post will cover how they work, and show an example of a simple version for creating custom Pokémon sprites.

## [](#generation)Generation
A large portion of machine learning models are inherently probabilistic in that they model the relation between an observed input $x$ and its target $y$. We distinguish between ***discriminative*** models and ***generative*** models. A discriminative model describes the conditional distribution $p(y|x)$, which could be a class $y$, based on some input $x$. A generative model describes the joint distribution $p(x,y)=p(x|y)p(y)$, which describes how the observed data is produced. In simpler terms, the former is a classifier/regression model, and the latter generates samples from our data distribution. 

![ml_model_types]({{ site.baseurl }}/assets/images/vibe-coding/ml_model_types.png "ml_model_types")

So, in both cases, the internal state of a model describes how the data is structured (or "distributed"), but is done so differently depending on the task. For classification, you would *condition* the model to some observed data, and then define the distribution of the outputs, by explicitly defining the probability of each possible output class. For generation, we need a way to describe how the observed data is distributed, while taking the output into account as well, as these are naturally linked. 

### How do we define a distribution?
In the classification case, all the classes are assigned a probability, given some input. These probabilities sum to 1 and are non-negative, which describes a ***probability distribution***. A linear regression model only outputs a single number or *estimate*, but underlyingly defines a gaussian distribution around the estimate, with the residuals determining the variancce. 

It is not as straight forward with generative models. For classification, you might want to estimate the probability between 10 classes, wheres with generative models you should in theory apply a probability to any possible image, matching the desired resolution. Defining the joint distribution is therefore less striaght forward, and there are many approaches to this.
